  <name>Task 3: Sim-clock module</name>
  <files>packages/contracts/src/sim-clock.ts</files>
  <action>
    Pure sim-clock math (ARCHITECTURE.md §sim-clock; the worker/db mirror lives in 02-01):
    ```ts
    export interface ClockState { epochSimMs: number; startedAtRealMs: number; speed: number; pausedAtRealMs: number | null; }
    export const simNow = (c: ClockState, nowRealMs: number): number =>
      c.pausedAtRealMs !== null
        ? c.epochSimMs + (c.pausedAtRealMs - c.startedAtRealMs) * c.speed
        : c.epochSimMs + (nowRealMs - c.startedAtRealMs) * c.speed;
    export const rebase = (c: ClockState, nowRealMs: number, newSpeed: number): ClockState =>
      ({ epochSimMs: simNow(c, nowRealMs), startedAtRealMs: nowRealMs, speed: newSpeed, pausedAtRealMs: null });
    ```
    Default `SIM_SPEED=60` (1 real min = 1 sim hour; a full sim-day passes in 24 real minutes → DDS always has a fresh "yesterday" during a demo). Rebase on every speed change so past sim timestamps are immutable (piecewise-linear mapping).
    STANDING RULE (add as a comment block + repo convention): downstream derivation code must NEVER call Date.now()/new Date() to compute durations — all math uses event `simTime`. Wall-clock is allowed only for: MQTT/infra concerns, `ingested_at` audit columns, and feeding `nowRealMs` into simNow at the clock edge.
  </action>
