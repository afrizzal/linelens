  <action>
    - `docker-compose.yml` services:
      - `db`: image `postgres:18` (exact pin per STACK.md), env from `.env` (`POSTGRES_USER=linelens`, `POSTGRES_PASSWORD`, `POSTGRES_DB=linelens`), volume `postgres-data`, healthcheck `pg_isready -U linelens` (interval 5s, retries 10).       - `mqtt`: image `eclipse-mosquitto:2.0.22` (NOT :latest, NOT 2.1 RC), mounting `docker/mosquitto/mosquitto.conf`, volume `mosquitto-data`, ports 1883. Healthcheck: `mosquitto_sub -t '$SYS/#' -C 1 -i healthcheck -W 3`.
      - `simulator`, `worker`, `web`: built from `docker/app.Dockerfile` (node:24-slim, pnpm via corepack, one image, different commands — AIDA's proven one-image shape). All three `depends_on` db+mqtt with `condition: service_healthy` (PITFALLS.md: compose startup ordering). `web` ports 3000.
    - `docker/mosquitto/mosquitto.conf`:
      ```
      listener 1883
      allow_anonymous true
      persistence true
      persistence_location /mosquitto/data/
      ```
      `persistence true` is REQUIRED — STACK.md: QoS1 + clean:false session state is silently lost on broker restart without it.
    - `.env.example` with all vars + comments: `POSTGRES_PASSWORD=linelens-dev`, `DATABASE_URL=postgresql://linelens:linelens-dev@db:5432/linelens`, `MQTT_URL=mqtt://mqtt:1883`, `SIM_SPEED=60`, `SIM_SEED=42`. For host-side dev: `DATABASE_URL` localhost variant in a comment.
  </action>
