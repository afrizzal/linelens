<task type="auto">
  <name>Task 3: Loss ledger emission (the Six Big Losses rules)</name>
  <files>apps/worker/src/derive/losses.ts</files>
  <action>
    EXACT RULES (verified — do not improvise):
    1. **DOWN interval closes** → one loss_event: factor AVAILABILITY, category UNPLANNED_STOPS, reasonCode = interval.reasonCode, window = interval, lostTimeSec = duration.
    2. **CHANGEOVER interval closes** → read machine.changeoverTargetMin (master data) and EngineConfig.changeoverAsPlanned:
       - policy true (default): `min(dur, target)` → PLANNED_STOPS (reason CO-PRODUCT/CO-CLEAN from interval); `max(0, dur − target)` → a SECOND loss_event, UNPLANNED_STOPS, reason CO-OVERAGE, windowStart = start+target. (Verified planned→unplanned overage transition, §2.)
       - policy false: single loss_event PLANNED_STOPS for the full duration (no overage split). Either way changeover time reduces Run Time (it is inside PPT).
    3. **ALARM MICROSTOP** → loss_event: factor PERFORMANCE, category SMALL_STOPS, reason = event.reasonCode, windowStart = simTime − durationSec, windowEnd = simTime, lostTimeSec = durationSec.
    4. **Slow cycles (residual, per closed shift-bucket)**: when a (machine, shiftInstance) window fully elapses (shift end < newest processed simTime), compute from that shift's data:
       `runTimeSec = PPT − Σ(DOWN) − Σ(CHANGEOVER)` (clamped interval overlaps with the shift window; PPT from contracts calendar);
       `pLossTotalSec = max(0, runTimeSec − Σ(idealCycleTimeSec × (goodDelta+rejectDelta)))` over COUNTS in-window (use each event's own ICT — product changes mid-shift are thereby handled);
       `slowCyclesSec = max(0, pLossTotalSec − Σ smallStopsSec-in-window)` → upsert ONE loss_event per (machine, shift): SLOW_CYCLES, reason SL-SPEED, window = shift window, shiftDate/shiftId set.
    5. **Rejects (per COUNTS event with rejectDelta>0)** → loss_event factor QUALITY: category STARTUP_REJECTS if rejectReason==RJ-STARTUP else PRODUCTION_REJECTS; reason = rejectReason; lostUnits = rejectDelta; lostTimeSec = rejectDelta × idealCycleTimeSec; window = [simTime, simTime]; `sourceEventId` = the COUNTS MachineEvent id. Replaying the same raw event upserts the same ledger row (the Task 1 unique key includes sourceEventId) — never accumulate-on-conflict, that is not replay-safe.
    Tag every loss_event with shiftDate/shiftId via contracts.shiftInstanceAt(windowStart).
  </action>
  <verify>Unit tests per rule with hand-built fixtures, incl.: changeover 20 min vs target 15 → exactly two rows (15 min PLANNED_STOPS + 5 min CO-OVERAGE UNPLANNED_STOPS); policy=false → one 20-min PLANNED_STOPS row; microstop alarm 45s → SMALL_STOPS 45s; full-shift fixture where pLossTotal=20min and microstops=8min → SLOW_CYCLES 12min; replay every fixture → identical ledger.</verify>
